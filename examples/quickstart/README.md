# Quickstart

There's no standalone script in this directory yet — the quickstart walkthrough
lives in two places, both verified against the real server/client:

- The root [README.md](../../README.md#quick-start-in-3-steps) for the
  fastest path (start the server, install the SDK, run the multi-agent demo).
- [docs/getting-started.md](../../docs/getting-started.md) for a slower,
  step-by-step version: raw `curl` requests against `/amp/v1/memories`, then
  the same operations through the Python SDK client.

If you want a runnable example instead of a walkthrough, see
[examples/multi-agent-demo](../multi-agent-demo/).
